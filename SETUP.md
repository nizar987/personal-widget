# Setup

The step-by-step setup guide now lives in [README.md](README.md#setup-first-time):

1. Install Rust
2. Start the backend (`./backend/scripts/install-launch-agent.sh`)
3. (Optional) import existing tasks
4. Set the signing Team in Xcode for both targets
5. Build and copy `TaskWidget.app` to /Applications
6. First launch from the menu bar, enable *Open at login*
7. Add the widget to the desktop
8. Try quick capture with ⌥Space

The API reference is in [backend/README.md](backend/README.md#api).
